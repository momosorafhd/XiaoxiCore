# XiaoxiCore · 小希助手框架

在 Linux 上运行的单主人私聊助手。Core 管理 QQ 消息队列、角色和提示词、记忆、日记、后台任务及主人管理台。部署者管理自己的 DSH（DeepSeek Harness，模型与会话宿主）和 SnowLuma（QQ 的 OneBot 渠道）。本仓库提供它们与 Core 之间的适配代码。

默认配置只监听 `127.0.0.1:18910`，使用空数据目录、新建的管理密码和离线消息桥。管理台可独立使用。真实私聊需要在管理台填写主人 QQ 和机器人 QQ，连接两个桥，再启动助手收件。面向 Linux 用户；其他系统由部署者自行适配。

```text
主人私聊 → SnowLuma → 消息桥校验账号 → 助手队列 → DSH 会话桥 → 模型
                                        ↑                 ↓
                                        └─ 记忆检索、工作回交 ─┘
主人 QQ  ← SnowLuma ← 消息桥核对收件人 ← 助手接收本轮结果
```

记忆在模型选择搜索、读取工具后进入上下文。停机期间的来信按消息编号补收，手机可以保持在线。新实例若给另一位主人使用，应使用独立的 Core 数据目录、DSH 工作目录和会话账本。

维护者可以用合成模型和本机协议对端复验。真实账号是否连通、模型是否按预期调用工具，需要在部署者自己的环境验收。原创代码采用 MIT 许可。[LICENSE](LICENSE) · [第三方说明](THIRD_PARTY.md)
