# 首次公开版本的验证范围

以下结果来自独立 Linux 测试目录，使用临时凭据、初始数据库和虚构账号。部署者可以按[架构与验收](开发与验收.md)重复测试。

| 检查 | 已验证 |
| --- | --- |
| Core、管理台及业务插件 | 使用锁定依赖从空虚拟环境安装，99 项平台测试通过。覆盖密码登录、配置保存与重载、主人白名单、回环 OneBot 收发、消息编号补收、记忆和日记、后台任务及恢复。 |
| 两个随包的 DSH 插件 | 31 项 Node 测试通过。会话桥另在 DSH `0.2.2-rc.2` 进程内加载，合成模型收到原生与业务提示，图书馆工具调用后返回结果，卸载和重挂后可继续工作。 |
| 原生提示差异 | 八个目标文件按完整哈希验证。在独立副本完成应用、恢复原文、重新应用与幂等检查。 |
| 局域网与网页登录 | 两份示例配置通过 Nginx 的配置检查和真实 HTTPS 代理请求。Core 登录后，随包网页插件通过 Unix 套接字取得测试用 DSH 网页凭据，退出后回到登录。DSH 网页签发接口使用测试替身。 |

真实 QQ、模型账号和使用者的内网证书需要在各自的部署环境验证。模型会在何时主动搜索记忆、长时间离线后 SnowLuma 能覆盖多少条好友历史，应以实际运行日志和消息编号为准。
